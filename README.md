# Introduction to ASP.NET Core

ASP.NET Core — кроссплатформенный, высокопроизводительный фреймворк от Microsoft для создания современных веб-приложений и API. Этот репозиторий содержит примеры и шаблоны проектов на ASP.NET Core.

## Короткое описание
В этом репозитории собраны демонстрационные проекты и примеры конфигурации для разработки приложений на ASP.NET Core. Цель — показать базовую структуру проекта, примеры настройки, сборки и развёртывания.

## Основные возможности
- Кроссплатформенность (Windows, macOS, Linux)
- Высокая производительность
- Встроенная поддержка Dependency Injection
- Конфигурируемый конвейер обработки запросов (middleware)
- Интеграция с Entity Framework Core, Identity и другими библиотеками

## Требования
- .NET SDK 6.0 / 7.0 / 8.0 (уточните, какую версию вы используете)
- Git
- (Опционально) Docker — для контейнеризации

## Быстрый старт
1. Клонируйте репозиторий:

   git clone https://github.com/Ismatjonov/AspNetCore.git

2. Перейдите в каталог проекта (пример):

   cd AspNetCore/MyProject

   Примечание: замените `MyProject` на реальный путь к проекту внутри репозитория.

3. Восстановите пакеты и соберите проект:

   dotnet restore
   dotnet build

4. Запустите приложение:

   dotnet run --project ./MyProject/MyProject.csproj

   Для режима разработки с авто-перезагрузкой используйте:

   dotnet watch run

## Структура репозитория (примерная)
- /src — исходники основных проектов
- /tests — модульные/интеграционные тесты
- /docs — дополнительная документация
- README.md — этот файл

(Если структура отличается, обновите раздел под конкретный репозиторий.)

## Конфигурация
- appsettings.json — основная конфигурация приложения
- appsettings.Development.json — переопределения для среды разработки
- Для секретов и строк подключения используйте переменные окружения или Secret Manager (`dotnet user-secrets`) в режиме разработки.

## Запуск в Docker (примеры)
1. Сборка Docker-образа:

   docker build -t my-aspnetcore-app .

2. Запуск контейнера:

   docker run -d -p 5000:80 --name myapp my-aspnetcore-app

(Добавьте Dockerfile в корень проекта, если ещё не добавлен.)

## Тестирование
- Запуск всех тестов:

  dotnet test ./tests

Убедитесь, что все тесты проходят перед созданием Pull Request.

## Вклад и правила кодирования
- PR приветствуются — оформляйте Pull Request с описанием изменений.
- Перед PR убедитесь, что проект собирается и тесты проходят.
- Используйте .editorconfig и анализаторы стиля кода, если они настроены.
